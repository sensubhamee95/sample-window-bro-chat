This page is served over HTTPS, but the API URL you entered uses plain HTTP. Browsers silently block these requests — that's why you see 0.0 kB / 0 ms in the Network tab.

You have two options to fix this:

✅ Option A — Change API URL to HTTPS

Put an Nginx reverse proxy with SSL in front of your backend and update the URL above to https://. Add this to your Nginx config on the API server:

proxy_pass http://127.0.0.1:5005; proxy_buffering off; proxy_read_timeout 300s;
✅ Option B — Proxy via your own server (no SSL on API needed)

In the Nginx config of the server hosting this HTML, add:

location /api/ {   proxy_pass http://37.27.180.36:5005/api/;   proxy_buffering off;   proxy_read_timeout 300s; }

Then set the URL field above to just http://localhost or leave blank (empty = same origin).
